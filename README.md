## Projets

- 🤖 **Top Serveursˢᶻ**  
  - Bot Discord permettant de consulter des informations, statistiques et classements autour des serveurs référencés sur Top Serveurs.  
  - **Langue** : 🇫🇷 Français, 🇬🇧 Anglais, 🇩🇪 Allemand, 🇪🇸 Espagnol, 🇮🇹 Italien, 🇵🇹 Portugais, 🇷🇺 Russe, 🇺🇦 Ukrainien, 🇯🇵 Japonais, 🇨🇳 Chinois  
  - **Stack** : Node.js / TypeScript / Discord.js / MySQL  
  - **Lien** : ❌

- 👀 **Watcherˢᶻ**  
  - Bot Discord de surveillance en temps réel pour suivre l’état de vos bots et recevoir des alertes configurables dans un salon, par rôle ou en message privé.  
  - Dashboard web de gestion et support multi-bots.  
  - **Langue** : 🇫🇷 Français, 🇬🇧 Anglais  
  - **Stack** : Node.js / JavaScript / Discord.js / MySQL  
  - **Lien** : [watcherbot.szdev.fr](https://watcherbot.szdev.fr)

- 🎨 **Copymojiˢᶻ**  
  - Bot Discord permettant de copier rapidement des emojis personnalisés entre serveurs via des commandes slash.  
  - Support des emojis animés et affichage détaillé des emojis.  
  - **Langue** : 🇫🇷 Français, 🇬🇧 Anglais  
  - **Stack** : Node.js / JavaScript / Discord.js / MySQL 
  - **Lien** : [copymoji.szdev.fr](https://copymoji.szdev.fr)
